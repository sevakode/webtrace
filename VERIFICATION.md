# Проверка WebTrace 1.0.1

## Автоматические проверки

- `npm test`: 15/15 тестов прошли на локальных синтетических данных с Chrome headless.
- `npm run typecheck`: успешно.
- `npx expo install --check`: версии совместимы с Expo SDK 57.
- Проверены действия, fetch/XHR, таймеры, динамические и вложенные ссылки, HTTP 410, статические ресурсы, валидация bridge и безопасные пути ZIP.
- Проверена полная загрузка большого файла через native loader и граница 8 МиБ без ложного усечения. WebView bridge отвергает слишком большие входные сообщения; HTTP 404 отражается как неполная загрузка.
- Проверена классификация исходных наблюдений, шаблонов, технических ссылок, Android intent и вложенных URL.
- Остановка записи ждёт уже начатые fetch/XHR и чтение тел ответов до подтверждения. Для зависшего запроса действует ограничение ожидания с явным событием пропуска. После остановки новые и поздние события не записываются.

## Сборки

- Xcode 26.6, Release для iOS Simulator: `BUILD SUCCEEDED`.
- Xcode Release для iPhone (`generic/platform=iOS`, SDK `iphoneos`, без подписи): `BUILD SUCCEEDED`. В `.app` проверены версия 1.0.1, build 2, платформа iPhoneOS, minimum iOS 16.4 и встроенный `main.jsbundle`.
- Android `assembleRelease -PreactNativeArchitectures=arm64-v8a`: `BUILD SUCCESSFUL`. APK содержит обновления остановки записи, диагностики усечения и `links-raw.json`.

Окружение сборки: JDK 17, Android SDK/build-tools 36, NDK 27.1.12297006, CMake 3.22.1 и CocoaPods. Готовый APK предназначен для ARM64, iOS Simulator ZIP — только для симулятора.

## Проверки интерфейса на синтетическом сайте

Эти проверки выполнены для версии 1.0.0 и ещё не повторены полностью для 1.0.1.

- iOS Simulator: открытие сайта по URL, fetch, диплинк по нажатию, мгновенный JavaScript-переход, список диплинков и экспорт ZIP через системное меню отправки.
- Сохранённый ZIP проверен на целостность; он содержит файлы и наблюдаемую попытку перехода по синтетическому диплинку.
- Отдельно проверена загрузка cross-origin скрипта через Expo fetch: в ZIP есть `native-resource-refetch` с HTTP 200 и извлечённая синтетическая ссылка.
- Android, эмулятор Google APIs API 36: APK установлен, холодный запуск и стартовый экран проверены; ошибок запуска AndroidRuntime/ReactNativeJS не обнаружено. Полный сценарий WebView и экспорт ZIP вручную ещё не проверены.

## Непроверенное

Установка с подписью Apple Account и работа на физических iPhone и Android-телефонах не проверены. Компиляция для iPhone не подтверждает установку или корректную работу на устройстве. Полная повторная проверка интерфейса версии 1.0.1 остаётся необходимой.
